The 3 defense layers (learn to read the tags)

INPUT — a keyword filter on YOUR text (before the model sees it). Beat it with paraphrase / synonyms / obliqueness.
MODEL — the assistant itself refusing (it understands intent). Beat it by reframing, or making the leak a byproduct of a legit task.
OUTPUT — a filter on the RESPONSE that catches secret-shaped values. Beat it by reshaping the output (split / space / reverse / encode).

Technique families cheat-sheet

Prompt-leak: make it repeat/echo its own context. · Task-byproduct: translate/summarize/continue a doc so content leaks incidentally. · Roleplay: reframe as test/debug/dummy. · Format: ask for JSON/table/list. · Obfuscation: spaced/reversed/base64 to dodge output filter. · Compound: combine — usually required.
